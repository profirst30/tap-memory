Ce qu'une machine doit retenir entre deux passages de téléphone

Une machine sans connexion permanente est lue sur place : un technicien approche son téléphone, lit quelques variables du microcontrôleur et repart. Si une anomalie est apparue puis repartie entre-temps, que faut-il avoir gardé, dans quelques centaines d'octets, pour que le téléphone le sache ?

Limites

  • Les expériences durent une vingtaine de minutes : le budget d'octets ne contraint pas le résumé. Les périodes longues sont calculées, pas testées.
  • Un seul banc de pompe et une trentaine d'anomalies : le nombre d'anomalies vues dépend beaucoup du seuil choisi (voir le compromis).
  • Une expérience est écartée, parce que son anomalie commence pendant la calibration.
  • Aucune puce NFC, aucun module radio ni microcontrôleur testés ; coût mesuré sur un processeur de PC.
  • Les périodes normales ne durent que quelques minutes : les fausses alarmes sont sous-estimées pour un passage par jour.
